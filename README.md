# Counter

**Counter** is a simple countdown timer app that displays the number of days remaining until 2026. It’s designed to be a lightweight, non-intrusive widget on your desktop, with a modern look and dynamic font color adjustment for maximum readability.

## Features

- **Countdown Timer**: Displays the number of days left until 2026.
- **Minimalistic Design**: Elegant and clean interface.
- **Desktop Widget**: Stays in the top-right corner of your screen, behind other apps.
